# Aero Internet v0.1

Небольшой интерактивный Frutiger Aero сайт.

## Запуск

Можно просто открыть `index.html` в браузере.

Для музыки положи свои MP3 в:

`assets/music/`

и поменяй пути/названия в `js/radio.js`.

## Картинки

В этой демо-версии Gallery использует emoji + CSS-арт, поэтому сайт запускается без дополнительных файлов. Позже можно заменить карточки на реальные изображения.

## Что уже работает

- адаптивная навигация;
- Home / Explore / Radio / Gallery / Games / Shop / Profile;
- локальный профиль;
- Aero Coins;
- рекорд Bubble Pop;
- сохранение данных через localStorage;
- музыкальный плеер;
- интерактивная карта;
- галерея/lightbox;
- мобильное меню;
- анимации.
